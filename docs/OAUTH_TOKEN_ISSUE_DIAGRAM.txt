╔══════════════════════════════════════════════════════════════════════════════╗
║ KEY INSIGHT: The Problem                                                     ║
╚══════════════════════════════════════════════════════════════════════════════╝

   Laravel's encrypted attribute casting caches the decrypted value in memory.
   When you call $connection->refresh(), it reloads attributes from the database,
   but the encrypted attribute cache is NOT cleared. The old decrypted value
   persists in the model instance.

   ┌─────────────────────────────────────────────────────────────────┐
   │  $connection->refresh()                                         │
   │  ├─→ Fetches fresh data from database ✅                        │
   │  ├─→ Updates model attributes ✅                                │
   │  └─→ BUT: Encrypted cache not cleared ❌                        │
   │      └─→ $connection->access_token still returns old value ❌   │
   └─────────────────────────────────────────────────────────────────┘


╔══════════════════════════════════════════════════════════════════════════════╗
║ KEY INSIGHT: The Solution                                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

   Instead of calling refresh() on the existing model instance, fetch a
   completely new instance from the database. This creates a fresh model
   with a new encrypted attribute cache containing the updated token.

   ┌─────────────────────────────────────────────────────────────────┐
   │  $connection = $user->office365Connection()->firstOrFail()     │
   │  ├─→ Creates NEW model instance ✅                              │
   │  ├─→ Fetches data from database ✅                              │
   │  ├─→ Decrypts access_token with FRESH value ✅                  │
   │  └─→ $connection->access_token returns NEW token ✅             │
   └─────────────────────────────────────────────────────────────────┘


╔══════════════════════════════════════════════════════════════════════════════╗
║ ADDITIONAL FIX: 5-Minute Buffer                                              ║
╚══════════════════════════════════════════════════════════════════════════════╝

   The fix also adds a 5-minute buffer to prevent tokens from expiring
   mid-request during long-running operations.

   WITHOUT BUFFER:                    WITH BUFFER:
   
   Token expires at: 10:00:00        Token expires at: 10:00:00
   Check at:         09:59:55        Check at:         09:55:00
   Decision:         Don't refresh   Decision:         Refresh now
   Request starts:   09:59:56        Request starts:   09:55:01
   Request ends:     10:00:05 ❌     Request ends:     09:55:05 ✅
                     (Token expired           (Fresh token, 5 min
                      during request)          remaining)

║ IMPLEMENTATION                                                                ║
╚══════════════════════════════════════════════════════════════════════════════╝

   Step 1: Add helper method to EmailSyncService.php (after line 23)
   
   private function ensureFreshAccessToken(User $user): \App\Models\Office365Connection
   {
       $connection = $user->office365Connection;
       if (! $connection || ! $connection->is_active) {
           throw new \Exception("No active connection");
       }

       // Check with 5-minute buffer
       $expiresAt = $connection->token_expires_at;
       $needsRefresh = ! $expiresAt 
                    || $expiresAt->isPast() 
                    || $expiresAt->diffInMinutes(now(), false) <= 5;

       if ($needsRefresh) {
           // Refresh token
           $tokenData = $this->office365Service->refreshAccessToken($connection);
           $connection->update([
               'access_token' => $tokenData['access_token'],
               'refresh_token' => $tokenData['refresh_token'],
               'token_expires_at' => $tokenData['expires_at'],
           ]);

           // 🔑 KEY FIX: Fetch fresh connection from DB
           $connection = $user->office365Connection()->firstOrFail();
       }

       return $connection;
   }

   Step 2: Replace all manual refresh logic with:
   
   $connection = $this->ensureFreshAccessToken($user);

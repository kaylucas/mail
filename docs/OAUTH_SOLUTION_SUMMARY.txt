ISSUE: Webhook notifications failing with 401 "token is expired"
STATUS: ✅ Solution Ready - Ready to Implement
PRIORITY: 🔴 CRITICAL

================================================================================
ROOT CAUSE ANALYSIS
================================================================================

PROBLEM:
- Webhooks from Microsoft Graph fail when OAuth access tokens expire
- Error: "InvalidAuthenticationToken - Lifetime validation failed"
- Location: EmailSyncService.php:491 (called from ProcessWebhookNotificationJob.php:112)

WHY EXISTING REFRESH FAILS:
1. refreshAccessToken() updates database ✅
2. $connection->refresh() attempts to reload ✅  
3. Laravel's encrypted casting caches decrypted value ❌
4. refresh() doesn't re-decrypt in same request ❌
5. $connection->access_token still contains OLD expired token ❌

RESULT: Graph API receives expired token → 401 error → webhook fails

================================================================================
SOLUTION OVERVIEW
================================================================================

APPROACH:
1. Add centralized token refresh helper method
2. Replace all manual refresh logic (4 methods)  
3. Fix encrypted attribute caching by fetching fresh connection from DB
4. Add 5-minute buffer to prevent mid-request expiration

BENEFITS:
✅ Fixes all webhook processing
✅ Eliminates 40 lines of duplicate code
✅ Consistent token handling across app
✅ Better logging and monitoring
✅ Prevents race conditions with buffer time
